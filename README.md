# Kinozettel HH

Watchlist für Hamburger Programmkinos. Jede Person öffnet die App über ihren persönlichen Link (`?k=…`).

- `index.html` – die App (statisch, GitHub Pages)
- `data/programm.json` – Kinoprogramm der nächsten 14 Tage, wird wöchentlich aktualisiert
- Watchlists & Profile liegen in Supabase, Zugriff nur über die `kz_*`-Funktionen
